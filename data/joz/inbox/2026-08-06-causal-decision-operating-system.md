# Causal Decision Operating System

The causal decision operating system connects data, candidate causal
discovery, human review, structural causal models, intervention analysis,
counterfactual simulation, and controlled action orchestration.

The flow is:

```text
Data sources and event streams
  → candidate causal discovery
  → domain and human review
  → identification, estimation, and refutation
  → versioned causal knowledge graph
  → decision and simulation layer
  → approval-gated action
  → verification against authoritative state
```

Joz's existing knowledge base remains the foundation for identity, experience,
architecture, skills, business value, and governance. This dataset adds the
decision-intelligence layer that explains how those capabilities can be
organized into a controlled causal operating system.
